# 바람결 결투장

친구와 서로 다른 컴퓨터에서 붙는 1대1 탑뷰 결투 게임입니다. 서버가 모든 판정(이동, 스킬 적중, 피해, 시야)을 계산하고 두 브라우저에 초당 30번 상태를 보냅니다.

## 폴더 구조

```
server.js          방 코드, 챔피언 선택, 준비, 게임 루프(60틱), 정적 파일 제공
game/sim.js        전투 시뮬레이션: 스탯, 스킬, 투사체, 바람 장벽, 시야, 라운드
public/index.html  화면 구조
public/style.css   디자인
public/art.js      챔피언 토큰 그림, 스킬 아이콘, 스킬 설명
public/client.js   렌더링, 보간, 입력, HUD, 이펙트, 미니맵
```

## 내 컴퓨터에서 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 탭 두 개를 띄우면 혼자서도 대전을 확인할 수 있고, "혼자 연습하기"로 움직이는 허수아비를 상대로 스킬을 연습할 수 있습니다.

## 친구와 인터넷으로 하기

### 방법 1. Render에 올리기 (추천, 무료)

1. 이 폴더를 GitHub 저장소로 올립니다 (`node_modules`는 빼고).
2. https://render.com 가입 → **New → Web Service** → 저장소 선택.
3. 설정:
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: `Free`
4. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 생깁니다. 이 주소로 둘 다 접속하면 됩니다.

무료 플랜은 15분 동안 아무도 접속하지 않으면 서버가 잠들어서, 처음 들어갈 때 30~60초 정도 걸릴 수 있습니다. 서버는 싱가포르(Singapore) 지역을 고르면 한국에서 지연이 가장 적습니다.

### 방법 2. 내 컴퓨터를 잠깐 공개하기 (설치만 하면 바로)

내 PC에서 `npm start`로 서버를 켠 상태에서 Cloudflare 터널을 열면 임시 주소가 생깁니다.

```bash
cloudflared tunnel --url http://localhost:3000
```

출력에 나오는 `https://xxxx.trycloudflare.com` 주소를 친구에게 보내면 됩니다. 터미널을 끄면 주소도 사라집니다.

### 방법 3. 같은 와이파이

같은 공유기에 있다면 친구가 `http://<내 PC의 IP>:3000` 으로 들어오면 됩니다. (Windows는 `ipconfig`로 IPv4 주소 확인, 방화벽에서 3000번 허용)

## 조작

| 키 | 동작 |
|---|---|
| 우클릭 | 이동 (꾹 누르면 계속 따라감), 적을 우클릭하면 기본 공격 |
| Q W E R | 마우스 방향으로 스킬 사용 |
| F 또는 D | 점멸 (400 거리) |
| S | 정지 |
| Tab | 조작 안내 숨기기 |
| Esc | 메뉴 (그만두기) |

## 규칙

- 먼저 3라운드를 이기면 승리. 라운드마다 체력, 쿨타임이 초기화됩니다.
- 시야는 1150 거리. 멀리 떨어지면 서로 안 보입니다. 서리궁수의 정찰 매로 밝힐 수 있습니다.
- 둘이 동시에 쓰러지면 그 라운드는 무승부입니다.

## 챔피언 요약 (수치는 `game/sim.js` 맨 위에서 바꿀 수 있음)

**질풍검객** 체력 1750, 치명타 50%
- 패시브: 이동하면 기류가 차고, 가득 찬 상태로 챔피언에게 맞으면 1초 동안 450 보호막
- Q: 사거리 475 찌르기. 2회 적중 후 세 번째는 사거리 1150 회오리(1초 띄우기). 돌진 중에 누르면 반경 375 원형 베기
- W: 4초 동안 적의 모든 투사체(기본 공격 화살 포함)를 지우는 장벽
- E: 적을 관통해 475 돌진. 같은 적에게는 6초마다. Q 쿨이 0.5초 이하로 남았으면 초기화
- R: 공중에 뜬 적에게 순간이동, 1초 붙잡고 내려침. 이후 15초간 치명타가 방어력 일부 무시

**망령검객** 체력 1720, 치명타 50%
- 패시브: 기본 공격 두 번째마다 피해 절반이 마법 피해
- Q: 사거리 470 찌르기. 2회 적중 후 세 번째는 450 돌진하며 0.75초 띄우기
- W: 부채꼴 600 범위, 최대 체력 10% 비례 피해, 맞히면 보호막
- E: 5초 동안 영혼 상태(이동 속도 증가). E 다시 누르거나 시간이 끝나면 몸으로 돌아오며 그동안 준 피해의 30%를 고정 피해로 다시 입힘. 공중에 뜨거나 기절하면 복귀가 미뤄짐
- R: 0.65초 뒤 1000 직선을 베고 맞힌 적 뒤로 순간이동, 끌어당겨 띄우기 (시전 중 군중 제어 무시)

**서리궁수** 체력 1600, 사거리 600, 마나 700
- 패시브: 모든 공격이 2초 둔화(치명타 시 둔화 두 배). 치명타는 피해 대신 기댓값만큼 고정 증폭
- Q: 기본 공격 4회로 충전, 마나 30. 6초 동안 공격 속도 +40%, 한 번에 다섯 발
- W: 화살 9발 부채꼴, 사거리 1200, 강한 둔화, 마나 60
- E: 정찰 매. 경로와 도착 지점을 5초 밝힘, 2회 충전
- R: 맵 끝까지 날아가는 수정 화살, 마나 100. 날아간 거리에 따라 1~3.5초 기절

## 밸런스 바꾸기

`game/sim.js`의 `CHAMPS`(기본 스탯)와 `CD`(쿨타임) 표, 그리고 `SKILLS` 안의 피해 계산식을 고치면 됩니다. 서버를 다시 시작하면 바로 반영됩니다.
